# 포트폴리오 콘텐츠 기준

기준일: 2026-10-26. 개인 이력의 우선 기준은 김성욱 본인이 제공한 경력과 승인한 포트폴리오 구성입니다. 최신 직책·날짜는 과거 소개문보다 이번 제공 이력을 우선했습니다.

| 항목 | 표현 범위 |
|---|---|
| WORKWAY / 레이어코퍼레이션 | 2023.09–2025.01 공동창업자·CTO, 개발 총괄·아키텍트·TPM, 근전도 웨어러블 서비스의 네이티브 앱·클라우드 개발과 운영 |
| IRIT-Agent | 자연어와 기하 모델링 도구를 연결하는 에이전트 기획·개발 |
| CADGen | 텍스트·치수 기반 CAD 생성 기획·개발과 기술 검증; 상용 성과로 표현하지 않음 |
| 해운물류 에이전트 | 연구실 개발 과제, 도메인 문서·업무 지원, Google ADK·문서 검색 경험 |
| 클라우드 프로젝트 | 팀장, OpenClaw 연동·개발 가이드·통합 검증·테스트·발표; 팀 전체 구현을 단독 성과로 표현하지 않음 |
| TeamClaw | 문서 작업용 에이전트 협업 도구의 프로토타입 기획·개발 |
| DrillMusic | AI DJ 팀 프로젝트의 팀장·PM·에이전트·애플리케이션 개발 참여 |

공개 링크는 [개인 GitHub](https://github.com/wannabidr), [클라우드 팀 프로젝트](https://github.com/wannabidr/cloud-computing-term-project), [DrillMusic](https://github.com/wannabidr/aibooster-drillmusic)에 한정했습니다. 비공개 프로젝트는 본인이 허용한 이름·목적·기술 요약만 사용했습니다.

WORKWAY 기술 요약에는 검토한 Bluetooth 연동·운동 기록/리포트·Swift/Kotlin/Firebase 구성을 반영했습니다. 모델 연구·하드웨어 설계·팀원의 구현까지 단독으로 수행했다는 주장, 검증되지 않은 성능 수치·고객·매출·출시 성과는 넣지 않았습니다. 내부 소스·설계·문서·비공개 저장소 링크는 포함하지 않았고 앱 실행 중 해당 저장소를 조회하지 않습니다.

아래 이력은 페이지에 모두 반영했습니다.

- 2026.05–현재: 부산대학교 창업동아리 개인의창업 팀장, 창업 준비.
- 2025.07–현재: 부산대학교 그래픽스 및 기하처리 연구실 학부연구생·에이전트팀장, 에이전트 프로젝트 4개 운영.
- 2025.09–2025.12: AID 에이전트 마중나가기 스터디팀장.
- 2025.03–2025.08: AID AX 앞서가기 스터디팀장.
- 2023.09–2025.01: 레이어코퍼레이션 CTO·공동창업자.
- 2022.11–2023.08: 부산대학교 PlayGround 개발팀장.
- 2025.09.19: AID 세미나 「20년 공부하고 딸깍으로 대체되기」 강연.

사진·이메일·전화번호 등 추가 개인정보는 게시하지 않았습니다. 과거 회사 경력과 현재 창업 준비 상태는 구분했습니다. WORKWAY 카드와 첫 화면의 그래픽은 제품 화면이나 실측 데이터가 아닌 기술 경험을 나타내는 장식입니다.
